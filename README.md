# School Policy AI

Proyecto: aplicación web con portal administrativo para consultas de políticas escolares y normativas.

## Objetivo
Crear una plataforma con:
- 4 perfiles de usuario: Profesores, Alumnos, Personal Directivo, Padres de Familia.
- Módulo IA para interpretar políticas y normativas del colegio.
- Panel administrativo de gobernanza para actualizar normas y aprobar cambios.
- Canal futuro opcional de WhatsApp para consultas.

## Estructura inicial
- `app/` - frontend web principal y rutas de usuario.
- `src/` - código compartido y lógica de aplicación.
- `api/` - backend de datos, autenticación, IA y gestión documental.
- `docs/` - diseño, arquitectura y decisiones de producto.

## MVP recomendado
1. Portal administrativo para cargar políticas, definir roles y versionar normas.
2. Interfaz consultiva para realizar preguntas sobre procedimientos y conducta.
3. Motor IA de búsqueda semántica + referencias normativas.
4. Control de acceso y auditoría para el personal directivo.
